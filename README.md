## Featured work

### Agentic AI System in Software Engineering

*Master's thesis · University of Zurich × Ergon Informatik AG · Feb – Jul 2026 · Grade 5.75/6.0*

An AI system that works as a shared member of a software team rather than one developer's personal assistant. An orchestrator coordinates specialized agents for coding, testing, pull-request review and log analysis, connected to Jira and Bitbucket. Together with Ergon's engineers I gathered requirements, integrated the system into a sandbox environment and evaluated it over three weeks with nine developers, measuring its impact on developer productivity and human–AI collaboration.

**Stack:** Agentic AI · LLMs · multi-agent orchestration · Jira · Bitbucket

### SafeGPT · Eraneos

*Developer in an international Scrum team · Eraneos Switzerland AG*

Eraneos' internal, privacy-compliant AI assistant platform: a secure multi-model chat solution that runs LLMs from several providers (e.g. Google Gemini and Anthropic Claude) inside a controlled environment. I contributed features, bug fixes and security improvements across the back end and front end, with code reviews in GitLab:

- **Adoption:** presentations, live demos, use cases with sales and back office, and a modular training program

**Stack:** Python · FastAPI · PostgreSQL + pgvector · React · TypeScript · Vite · GitLab

### [Nexa Platform](https://github.com/nexa-platform/nexa-platform)

*Master's project · University of Zurich · piloted for two weeks with licensed therapists*

A therapist-centric no-code platform to design, supervise and evaluate AI counseling agents. Therapists create counseling plans and reusable exercises, configure client-facing chatbots (including document uploads), assign GAD-7 questionnaires, and review journals and transcribed meetings with AI summaries. A therapist assistant ("Eliza"), interaction monitoring with harmful-content alerts and client-activity dashboards support supervision. Built with a Design Thinking (Double Diamond) and agile process.

**Stack:** Java 21 · Spring Boot · PostgreSQL · Hibernate · TypeScript · React · Vite · MUI · OpenAPI Generator · Docker · Kubernetes · GitHub Actions · SonarCloud<br>
**LLMs:** Gemma 3 12B self-hosted at UZH and Azure OpenAI GPT-4.1 (Sweden Central)

### Business Network Advisor · Eraneos

*Built end to end, from concept to MVP · Eraneos Switzerland AG*

An AI advisory chatbot for optimizing business networks, with RAG-based document retrieval, conversation memory and context-driven dialogue logic. It runs on locally hosted Llama models (AnythingLLM, LM Studio) and uses SCION for secure data transmission. Presented in live demos to Eraneos' TMT community.

**Stack:** React · Vite · Java · Spring Boot · Llama · RAG · SCION · Azure
